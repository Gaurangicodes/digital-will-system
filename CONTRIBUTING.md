# Contributing

Thanks for your interest in the Digital Will System. The project is in the planning stage, so contributions are currently documentation and design feedback.

## How to Contribute

1. Open an issue to discuss your idea or correction
2. Fork the repository and create a branch (`docs/short-description`)
3. Make focused changes and describe them in your pull request
4. Wait for review from a maintainer

## Guidelines

- Keep documents clear and consistent with existing terminology
- Do not include private keys, seed phrases or personal data anywhere
- Report security concerns privately, as described in [SECURITY.md](SECURITY.md)
- Be respectful, as described in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md)
