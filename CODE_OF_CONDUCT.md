# Code of Conduct

We want this project to be welcoming and respectful for everyone.

**Expected behavior:** be kind, give and accept constructive feedback, respect different experiences and viewpoints.

**Unacceptable behavior:** harassment, discrimination, personal attacks, publishing others' private information, or any conduct that would be inappropriate in a professional setting.

Maintainers may remove comments, contributions or participants that violate these standards. Report concerns to the maintainers through the repository's private contact method.
