# Security Policy

## Status

This repository currently contains documentation only. No production code or deployed contracts exist.

## Reporting a Vulnerability

If you find a security issue in the design or in any future code, please do not open a public issue. Contact the maintainers privately (for example through GitHub's private vulnerability reporting) with a description and steps to reproduce.

## Future Practices

- Use audited libraries (OpenZeppelin, Safe)
- Run static analysis (Slither) on all contracts
- Complete an external audit and run a bug bounty before any mainnet release
