# Roadmap

## Hackathon MVP

- Safe-style vault and inheritance module on Sepolia
- Configurable short heartbeat for live demo
- 2-of-3 guardian confirmation
- Merkle-based beneficiary claim
- React dashboard with status, next check-in and guardians

## Production

1. External audit and bug bounty
2. Multi-chain and L2 support
3. Legacy vault with Shamir-based key release
4. Legal executor portal and exportable records
5. Mobile app and push-based check-ins
6. Hardware wallet and account abstraction (EIP-4337) support
